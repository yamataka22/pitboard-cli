## pitboard task unarchive

アーカイブを解除する（タスクは元の担当・進捗カラムに戻る）

```
pitboard task unarchive NUMBER --yes [flags]
```

### Options

```
  -h, --help           help for unarchive
      --space string   スペース ID（省略時は既定スペース）
      --yes            書き込みを確認したことを示す（必須）
```
